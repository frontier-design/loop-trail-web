# Loop Trail CMS Image Guidelines (Client Share)

This guide lists the recommended image specs for each page/section in Strapi.

## Global Recommendations

- Preferred formats: `WebP` (photos), `PNG` (graphics with transparency), `SVG` (logos/icons).
- Keep color profile to `sRGB`.
- Use clear filenames (e.g. `home-cta-background-2400x1350.webp`).
- Avoid screenshots where possible; export original design assets.
- If an image looks soft on Retina displays, upload a higher-resolution source.

## Notes for Editors

- Crop to the target aspect ratio before uploading to avoid unexpected composition cuts.
- For photos with text, keep important text away from image edges.
- For logos, upload transparent backgrounds where possible.
- Replacing media keeps the same field/key; no frontend code changes are needed when only assets are updated.
